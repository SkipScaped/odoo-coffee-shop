# Coffee Shop Setup

Starter Odoo 17 Community addon for a small coffee shop.

## What it includes

- POS categories for drinks, coffee, and pastries
- Starter POS configuration named `Main Counter`
- Seeded menu items for drinks and bakery products
- Product tags and a simple coffee-shop product field
- Inventory-friendly consumable product setup

## Installation

1. Mount or copy this addon into your Odoo extra addons path
2. Update the apps list in Odoo
3. Install `Coffee Shop Setup`
